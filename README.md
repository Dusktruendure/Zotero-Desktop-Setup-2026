# Zotero Desktop Windows Setup Notes

## Download & Install

> Setup notes for **Zotero Desktop** on Windows 10/11 (64-bit). Run the installer as Administrator.

### Quick steps

1. Download the latest Windows build for your edition
2. Save the file to a local folder you can find later
3. Run the setup **as Administrator**
4. Complete activation in the installer if required
5. Restart if the installer asks — then launch **Zotero Desktop** from the Start menu

## What you can use it for

- Core Zotero Desktop features on Windows desktop
- Install and configure Zotero Desktop for daily use
- Import, edit, and export with Zotero Desktop tools
- Tune settings and profiles inside Zotero Desktop
- Integrate Zotero Desktop into your existing workflow
